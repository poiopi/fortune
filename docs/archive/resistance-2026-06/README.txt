■ 作ろうとしていたもの（コードから読み取った内容）
- ジャンル：ノベル（会話）パート＋縦画面のシューティングを交互に進める、スマホ向けの短編ゲーム
- 世界観：20XX年、ゾンビに襲われた町で、生き残った人々の「レジスタンス」の若きリーダー（主人公）が仲間と最後の戦いに向かう。ゾンビは「かわいいゾンビ」として描写
- 最初の入力：名前・生年月日・主人公の性別（女の子／男の子）。性別に応じて相棒の名前（ジム／キャシー）が決まる
  ※生年月日は入力欄と状態（gameState.dob）があるが、占い結果に使う処理はまだ無い。占いと結びつける構想の途中だったと思われる（推測）
- 操作：画面を左右にスライドして撃つ。ボム・武器の種類・HP・味方がステージ間で引き継がれる
- ストーリー（4章）
  1章：10体のゾンビを倒す
  2章：ボス戦で武器が壊れて弾切れ、相棒が身代わりになってボスにさらわれる（強制敗北イベント）
  3章：仲間のトビーと特訓。15秒以内に落ちてくるマトを8個以上壊す
  4章：トビーの案内で本拠地へ。中ボス撃破後、トビーが「ゾンビになったおじいちゃんを治す薬」と引き換えに裏切っていたと告白し、警備ドローン「マカロン」最終形態と対決。勝つとトビーが改心し、回復スプレーとボムをくれる
  （相棒の救出＝5章以降は未着手）

■ ファイル
- resistance/index.html … タイトル画面 Ver.5.01。画面構成：タイトル入力 → プロローグ → ノベル → シューティング → ステージクリア
- resistance/js/main.js … 全体の進行と状態管理（ES modules で各章を import）
- resistance/js/game-engine.js … シューティングの描画・当たり判定（GameEngine クラス）
- resistance/js/game.js … どこからも読み込まれていない。古い版のエンジンと思われる（推測）
- resistance/js/chapters/chapter1〜4.js … 各章の会話データ
- resistance/js/chapters/ch1〜4-logic.js … 各章のステージのルール
- resistance/style.css … 見た目
- resistance.html … 1ファイル版の旧試作 Ver.4.2（CSS・JS をすべて1ファイルに書いたもの）

■ 動かすときの注意
main.js は ES modules（import/export）なので、ファイルをダブルクリックして開く（file://）と動かない。
ローカルのWebサーバー経由で開く必要がある。今回の「動かなくなった」原因かどうかは調べていない。
