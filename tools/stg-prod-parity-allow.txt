# 書式：パターン<TAB>種別<TAB>理由[<TAB>正規表現]
#   パターン：fnmatch。* は / をまたぐ
#   種別：
#     STG専用   … 恒久的にSTGだけ／STGだけ違う設定（ずっと残る）
#     管理画面   … 管理画面とその付属（ユーザー確認済み：管理画面は分けてよい）
#     保留中     … 意図してSTGだけに置いている未リリース分。日付・作業名・解消条件を書く。解消したら行を消す

# ここに書いていない差分は、すべて「想定外」として数える。
